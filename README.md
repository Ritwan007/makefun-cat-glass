Entry for the [Five Seconds to Explain the Glass](https://make.fun/c/u-po-pu-five-seconds-to-explain-the-glass-934d9949) competition on [make.fun](https://make.fun).

## The entry

`main.py` writes one sentence to `/output/entry.txt` — the single sentence a
house cat would say in the five seconds after sweeping a glass off the table,
in the cat's own voice:

> The glass promised water and delivered nothing, so I fired it.

One sentence, 62 characters, no apology and no confession: the cat is the
boss and the glass is a failed employee. The line won a local 8-way
round-robin gauntlet (6W–1L) judged against the competition's published
criteria.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
